# Tempo Task Tamer

Prompt: AI Productivity Assistant Web Application

Role: Act as an expert AI app developer and UI/UX designer.

Objective: Build an AI-powered web application that automates workplace tasks, saves time, and improves productivity.

Context: The application is designed for students, employees, and professionals who want to manage their daily work efficiently.

Requirements:

Smart Email Generator: Generate, rewrite, shorten, and improve professional emails with different tones.

Meeting Notes Summarizer: Summarize meeting notes, identify key points and decisions, and extract action items, owners, and deadlines.

AI Task Planner: Create, prioritize, schedule, and track tasks, deadlines, and progress.

Dashboard: Display tasks, upcoming deadlines, completed work, and quick access to all three tools.

User Interface: Provide a modern, simple, responsive, and user-friendly design.

AI Integration: Connect AI services and save user data securely.

Constraints: Use accurate information, protect confidential data, avoid inventing missing details, and ensure all features work correctly.

Output: Deliver a functional, professional web application that combines email generation, meeting summarization, and task planning in one place.

Main Goal: Help users work smarter, save time, and improve productivity.
